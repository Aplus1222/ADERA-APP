# Adere — Privacy Policy & Commitments

**Last Updated: 2026**

### Zero Telemetry & Offline Guarantee
1. **No Data Collection**: Adere does not collect, log, track, or share any personal data, passwords, emails, addresses, seeds, or account identifiers.
2. **Zero Network Connections**: Adere contains no network code, analytics SDKs, crashlytics reporting, advertising SDKs, or cloud server endpoints.
3. **No Account Required**: The application operates completely offline without user registration.
4. **Local Cryptography**: All cryptographic key derivations, authentications, and encryptions happen on-device using Android platform hardware and Java Cryptography Architecture.
5. **No AI Interception**: Vault contents, seed phrases, and passwords are never submitted to AI models or third-party APIs.
